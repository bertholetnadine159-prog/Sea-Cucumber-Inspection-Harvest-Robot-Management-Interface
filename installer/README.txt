SeaUI 水下机器人控制站 3.0.0
====================================

一、快速开始
1. 双击桌面或开始菜单的 SeaUI 图标（或安装目录下的 SeaUI.exe）。
2. 客户端会自动拉起同目录 backend\SeaUIBackend.exe（本地服务，仅监听
   127.0.0.1，不对外开放端口；若系统防火墙提示，请选择"允许访问"）。
   若客户端未能自动拉起，可先手动双击 backend\SeaUIBackend.exe 再打开客户端。
3. 在登录页输入账号与口令。初始超管账号口令由交付方在部署时提供
   （部署方可通过环境变量 ROV_SUPER_ADMIN_PASSWORD 设置随机初始口令，
   请勿沿用出厂默认口令对外交付）。
4. 安全要求：首次以超管身份登录时，系统会强制要求修改初始口令，
   修改成功后才能进入主界面。

二、数据与日志位置
- 本地数据库：%LOCALAPPDATA%\SeaUI\data\seaUI.db
  （卸载程序不会删除该数据库，重装后自动沿用历史数据）
- 双击 backend\SeaUIBackend.exe 可在控制台窗口查看后端运行日志。

三、运行模式（高级）
SeaUIBackend 通过环境变量 ROV_BACKEND_MODE 切换三种模式：
- rdk（默认）：连接 RDK X5 网关（ROV_RDK_HOST，默认 192.168.127.10，
  需与 PC 网线直连或同网段），视频/AI 检测/传感器全部来自真实硬件；
- local：PC 本地摄像头 + 内置 best.onnx 推理（无 RDK 时调试用）；
- sim：无硬件仿真，界面会显示"仿真数据"角标。
端口覆盖：ROV_WS_PORT（默认 8765）、ROV_API_PORT（默认 5000）。

四、常见问题
- 提示"连接后端失败"：检查 8765/5000 端口是否被占用，或后端进程是否被
  安全软件拦截；确认后已重新打开客户端。
- 网线直连 RDK X5 无数据：确认网线、RDK 电源，以及 PC 网卡地址配置。
- 开机自启动：安装时勾选"开机自动启动"即写入当前用户注册表 Run 项，
  卸载时会自动清理。
- 卸载：通过"控制面板 - 程序与功能"卸载 SeaUI；数据库保留在
  %LOCALAPPDATA%\SeaUI，如不再需要可手动删除该目录。
