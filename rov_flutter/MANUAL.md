## 系统概述

海参检测机器人管理系统是一套用于远程监控和操控水下ROV（遥控潜水器）的综合管理平台。系统采用 Flutter 跨平台技术开发，支持 Windows 桌面端和 Android/iOS 移动端。

### 主要功能
- 实时视频监控
- 机器人方向控制
- 设备状态监测
- 环境数据分析
- 系统配置管理
- 操作日志记录

---

## 环境要求

### 开发环境
- Flutter SDK 3.0+
- Dart SDK 3.0+
- Windows 10/11（桌面端开发）
- Visual Studio 2019+ 含 C++ 桌面开发组件

### 运行环境
- **桌面端**: Windows 10/11 (x64)
- **移动端**: Android 5.0+ / iOS 12.0+

## 安装与运行

### 1. 获取依赖
```bash
cd rov_flutter
flutter pub get
```

### 2. 运行应用

**Windows 桌面端：**
```bash
flutter run -d windows
```

**Android 设备：**
```bash
flutter run -d <device_id>
```

**iOS 设备：**
```bash
flutter run -d <device_id>
```

### 3. 构建发布版本

**Windows：**
```bash
flutter build windows --release
```

**Android APK：**
```bash
flutter build apk --release
```

## 桌面端操作指南

### 导航栏

顶部导航栏提供页面切换功能：

```
[Logo] 海参检测机器人管理系统  |  管理员  |  控制操作  |  主控  |  数据分析  |  设置  |  🔔  |  用户信息
```

点击对应标签即可切换页面。

### 1. 管理员面板

#### 今日核心概览
显示四个关键指标卡片：
- **今日巡检次数** - 当日完成的巡检任务数
- **实时报警统计** - 当前未处理的报警数量
- **机器人活跃率** - 在线机器人占比
- **云端存储空间** - 已使用的存储容量

#### 系统操作日志

> **数据源**: `assets/data/system_logs.txt`

| 列名 | 说明 |
|------|------|
| 操作时间 | 操作发生的日期和时间 |
| 操作人 | 执行操作的用户或系统 |
| 动作模块 | 操作所属的功能模块 |
| 动作内容 | 具体操作描述 |
| 状态 | 成功/警告/错误 |

**日志文件格式：**
```
时间|操作人|模块|内容|状态
2026-02-27 14:32:15|系统|设备管理|ROV-01 设备上线|success
```

**操作：**
- 使用搜索框筛选日志
- 点击【筛选】设置过滤条件
- 点击【导出】复制日志到剪贴板

#### 用户与角色

> **数据源**: `assets/users/{用户名}/` 目录

用户信息从目录结构读取：
```
assets/users/
├── 张伟/
│   ├── info.txt      # 角色和权限信息
│   └── avatar.png    # 头像图片（可选）
├── 李娜/
└── 王超/
```

**info.txt 格式：**
```
超级管理员
系统全权限,日志导出
```

点击【管理所有权限】进入详细设置。

#### 系统配置快选
- **数据自动备份** - 每24小时增量备份
- **AI异常自动识别** - 实时分析视频流
- **报警推送限制** - 仅限高级别预警

点击【运行全量自检】执行系统诊断。

### 2. 控制操作页面

#### 实时运行状态
三个状态卡片实时显示：
- **探测深度** - 当前机器人深度（米）
- **机器温度** - 机器内部温度（°C）
- **漏水检测** - 密封状态

#### 辅助系统控制

| 控制项 | 功能 |
|--------|------|
| 前端补光强度 | 拖动滑块调节（0-100%）|
| 机械臂展开 | 展开/收起机械臂 |
| 关闭主泵 | 控制主推进器 |
| 姿态自动调平 | 启用自动平衡 |
| 全景扫描 | 启动环境扫描 |

#### 方向控制面板

```
          [前进 ↑]                    [上浮]
   [左倾]        [右倾]
[左转 ←]   [●]   [右转 →]          [下潜]
          [后退 ↓]
```

- 左侧倾/右侧倾 与前进按钮居中对齐
- 上浮/下潜 在右侧垂直排列
- 点击对应按钮控制机器人移动方向
- 中心蓝色按钮为悬停状态指示

#### 紧急停止
**⚠️ 重要安全功能**

点击红色【紧急停止 (STOP)】按钮将：
1. 立即切断动力电池输出
2. 释放上浮气囊

> **警告**: 仅在紧急情况下使用！

### 4. 数据分析页面

> **数据源**: `assets/data/environment_data.csv`

#### CSV文件格式
```csv
日期,时间,PH值,水温,盐度,气压
2026-02-27,00:00,7.82,12.5,32.1,101.2
2026-02-27,01:00,7.85,12.3,32.0,101.3
```

#### 时间范围选择
```
[今日] [本周] [本月] [本年]  [导出 CSV]
```

#### 环境指标卡片
| 指标 | 单位 | 说明 |
|------|------|------|
| 实时PH值 | ph | 水体酸碱度 |
| 平均水温 | °C | 水体温度 |
| 盐度浓度 | psu | 盐分含量 |
| 气压水平 | kPa | 大气压强 |

#### 图表说明
1. **PH值动态趋势** - 折线图显示PH变化
2. **盐度浓度分布** - 柱状图显示盐度分布
3. **底层水温变化** - 折线图显示温度变化
4. **环境大气压强** - 折线图显示气压变化

#### AI智能分析看板
- 显示基于传感器数据的智能分析报告
- **采收适宜度** - 评估采收条件
- **环境预警** - 异常情况提醒
- **养殖建议** - 操作建议

**导出功能：**
- 点击【导出 CSV】将当前筛选的数据复制到剪贴板
- 点击【生成完整报告】导出详细分析报告

## 常见问题

### Q1: 应用无法连接到机器人？
**A:** 请检查：
1. 网络连接是否正常
2. 机器人是否已开机
3. 通信延迟是否过高（顶部显示）

### Q2: 视频画面卡顿？
**A:** 可能原因：
1. 网络带宽不足
2. 机器人信号弱
3. 降低视频分辨率设置

### Q3: 如何导出操作日志？
**A:** 进入管理员面板 → 系统操作日志 → 点击【导出】

### Q4: 忘记登录密码怎么办？
**A:** 点击登录页"忘记密码？"或联系系统管理员重置

### Q5: 如何切换深色模式？
**A:** 进入设置页面 → 主题模式 → 选择"深色模式"
