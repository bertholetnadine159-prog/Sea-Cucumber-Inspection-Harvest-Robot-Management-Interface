## 三、功能说明（开发完成的软件功能）

1. **登录与账户安全**：用户名/密码登录（REST `POST /api/login`），口令 PBKDF2-HMAC-SHA256 加盐哈希存储；超级管理员首登强制修改初始口令（`must_change_password` 机制），普通用户可在设置页自助改密；找回密码页引导联系管理员重置。
2. **主控页（实时监控中心）**：RDK X5 真实视频流显示（前视 camera_1 / 吸口 camera_2 切换）、分辨率/帧率/端到端链路时延（由 `frame.sent_ts` 实测）、YOLO11 分割检测框与置信度叠加、实时检测日志；深度、水温、电池电压/剩余电量、超声距离等遥测卡片；方向控制（W/A/S/D、Shift+空格键盘绑定）、一键上浮、照明开关、快照捕获。
3. **悬浮急停球**：屏幕右缘常驻悬浮球，长按充能即触发（免确认对话框，更快触达），经后端 ack 确认；未获确认升级为红色常驻告警直至恢复，发送失败如实提示。
4. **操作页**：按住推进、松开即停的方向控制（带推进器动力百分比）、紧急停止（带确认对话框）、吸捕抓取（吸力 100%）/释放（吸力 0%）、灯光控制、实时运行状态（深度/水温/电池电压/通信延迟）。
5. **数据分析**：全部消费 SQLite `source='rdk'` 真实记录；支持时间范围（1小时/6小时/24小时/7天/自定义）、聚合窗口（bucket 按窗口 AVG）、多传感器序列筛选（深度、压力、双路水温、双路光照、双路超声），min/max/avg/最新与趋势统计，CSV 导出，作业快照画廊（`list_snapshots`/`fetch_snapshot`，白名单目录校验）。
6. **管理与诊断（管理员页）**：KPI（用户总数、活跃会话、24h 控制日志、24h 传感器数据、数据库大小、后端运行时长，30 秒自动刷新）；用户与角色增删改、重置密码、启用/停用登录；操作日志检索、分页与导出；RDK X5 地址配置（保存后自动重连网关）；摄像头列表与能力；链路诊断（消费 `/api/health` 与 `/api/stats` 真实链路数据）。
7. **设置**：显示设置（明亮/深色/自动主题、界面缩放、全局字体大小）、语言与地区、账户与安全（修改密码）、RDK X5 连接、启动选项（开机自启）、无障碍（减少动画效果）、维护（清除缓存）、退出登录。
8. **板卡网关（RDK X5 端）**：双摄像头管理、hobot_dnn BPU YOLO11 分割推理与 JPEG 编码推流、`set_video` 宽/高/帧率/质量热更新；VEML7700/MS5837/DS18B20/LO81MTW 传感器采集；MAVLink 控制 Pixhawk 2.4.8 八路推进器与吸捕/舵机（死区看门狗、deadman_ms 超时回中、arm 魔数保护）；快照与诊断命令。
9. **PC 后端桥接服务**：UI WebSocket（ws://127.0.0.1:8765）强鉴权与命令转发、REST（http://127.0.0.1:5000）、SQLite 持久化（users/sessions/sensor_readings 含 source 标/control_logs/settings）、rdk/local/sim 三模式与数据来源打标。

## 四、技术特点

1. **真实数据回传，无假数据**：界面每个数值均溯源真实硬件链路（RDK X5 → 后端 → 界面）；视频/遥测/连接拆分为三条独立 `ValueNotifier` 通道（`videoFrameNotifier`/`telemetryNotifier`/`connectionNotifier`），消除每帧全页重建；无真实来源的坐标/GPS、信号强度、功率等假值已全部删除；数据断链超过 5 秒由 StaleBadge 显示"⚠ 信号丢失"徽标并冻结最后真实值，恢复后自动消失，不使用兜底假值；sim 模式全局显示"仿真数据"角标，与真实数据不混淆。
2. **强鉴权与角色控制**：WS 未携带有效 token 不执行命令；`auth` 完成前不推送视频/遥测流；arm/disarm/esc_calibrate 等危险命令仅 super_admin/admin 可发（WS 与 REST 同规则）；CORS 收敛为本机回环来源；控制命令全量写入 control_logs 审计。
3. **边缘 AI 推理**：YOLO11 海参分割量化模型（YOLO11_LBL.bin）在 RDK X5 BPU 上推理，标注视频经 WebSocket 实时回传，PC 端不跑模型推理。
4. **链路时延实测**：视频帧携带采集时刻 `ts` 与网关发送时刻 `sent_ts`，端到端时延 = 接收时刻 − `sent_ts`，时钟倒挂或缺失时显示为空，不造数。
5. **浅色商用级界面**：GitHub light 浅色设计语言（#F8FAFC 底、白色卡片、1px 浅灰描边），本地内置字体（Noto Serif SC / PT Serif / Inter，离线可用），页签 300ms 淡入上浮转场，支持"减少动画"无障碍开关（reduceMotion 时动画时长归零），新增动画控制器/计时器均在 dispose 释放。
6. **免环境交付**：后端以 PyInstaller onefile 打包为 SeaUIBackend.exe，Inno Setup 安装包交付，客户机器无需 Python 环境；RDK X5 端支持 systemd 常驻（开机自启、断线自动重启）。
