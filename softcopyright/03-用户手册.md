## 1. 系统概述与运行准备

### 1.1 功能说明

SeaUI海参检测及吸捕机器人管理系统（以下简称 SeaUI）是面向海参养殖与水下巡检场景的 ROV 管理与智能识别系统。系统由三部分组成：

- **PC 桌面客户端（SeaUI.exe）**：登录、主控、操作、数据分析、管理员与设置六大界面；
- **PC 后端桥接服务（SeaUIBackend.exe）**：WebSocket 强鉴权、REST 接口、SQLite 数据库，向上服务界面、向下连接板卡；
- **RDK X5 板卡网关**：双摄像头视频、YOLO11 海参分割推理、四类传感器采集、MAVLink 控制 Pixhawk 2.4.8。

控制链路：**SeaUI 桌面软件（PC）→ 网线 → RDK X5 → MAVLink → Pixhawk 2.4.8**。

界面展示的所有数值（视频、深度、水温、光照、电池、电机 PWM、AI 检测框等）均来自真实硬件链路回传，系统不使用任何兜底假值；仿真（sim）模式下的数据全程带"仿真数据"角标，与真实数据严格区分。

### 1.2 运行环境

| 项目 | 要求 |
| --- | --- |
| 计算机 | Windows 10/11 x64，内存 ≥ 4GB，分辨率 ≥ 1024×640（默认窗口 1440×900） |
| 网络 | PC 网口与 RDK X5 网线直连（板卡默认 IP 192.168.127.10，PC 需同网段） |
| 板卡 | 地瓜机器人 RDK X5（Ubuntu 22.04），已部署网关并运行 `run_robot.sh` 或 systemd 常驻服务 |
| 外设 | MIPI/USB 摄像头 ×2、Pixhawk 2.4.8 飞控、VEML7700 光照 ×2、MS5837 深度计、DS18B20 水温 ×2、LO81MTW 超声波 ×2 |

### 1.3 操作步骤（启动）

1. 双击桌面 `SeaUI.exe`（安装版）：客户端自动拉起内置后端，无需 Python 环境；
2. 等待窗口打开（默认 1440×900，可拖拽调整大小，最小 1024×640）；
3. 窗口底部状态栏右侧出现连接状态圆点与提示文字，进入登录界面后即可登录。

## 2. 启动与登录（含首次登录强制改密）

### 2.1 功能说明

登录页为浅色（GitHub light 风格）设计，中英双语标题「登录 (LOGIN)」。系统实行**强拦截登录**：用户名或密码缺失、错误一律返回 401 并阻止进入，不存在"访客放行"路径。口令在后端以 PBKDF2-HMAC-SHA256 加盐哈希存储，不存明文。

超级管理员首次使用初始口令登录时，后端返回"须强制改密"标记（`must_change_password`），客户端弹出强制改密对话框，**改密成功前无法进入主界面**。

### 2.2 界面元素

| 元素 | 说明 |
| --- | --- |
| Username / Password 输入框 | 输入用户名与密码（占位提示 Enter your username / Enter your password） |
| 登录 (LOGIN) 按钮 | 提交登录请求 |
| 忘记密码 (Forgot Password) 链接 | 跳转找回密码页 |

### 2.3 操作步骤（普通登录）

1. 在登录页输入用户名与密码；
2. 点击「登录 (LOGIN)」；
3. 校验通过后进入主界面，默认显示**主控页**；超级管理员、管理员额外可见「管理员」「数据分析」两个页签，普通用户这两项置灰并带锁形图标；
4. 校验失败时页面提示错误，不进入系统。

### 2.4 首次登录强制改密（超级管理员）

1. 使用初始口令登录成功后，自动弹出「请修改初始密码」对话框，提示"当前账号仍在使用初始口令，为保障系统安全，首次登录必须修改密码。"；
2. 输入**旧密码**、**新密码**、**确认新密码**；
3. 点击「确认修改」：两次输入不一致或校验失败时提示错误，修改成功后方可进入主界面；
4. 「暂不修改」仅关闭对话框，系统不允许在未改密状态下进入主界面。

### 2.5 找回密码

1. 在登录页点击「忘记密码 (Forgot Password)」；
2. 找回密码页提示：本系统暂不支持自助找回密码，请联系设备管理员重置——管理员登录后进入「管理员 → 用户与角色」，选择对应用户点击「重置密码」即可；
3. 点击「返回登录 (Back to Login)」回到登录页。

## 3. 主控页（实时监控中心）与悬浮急停球

### 3.1 功能说明

主控页是作业主界面，汇聚**RDK 真实视频流 + AI 检测 + 遥测仪表 + 推进器控制 + 快捷操作**。登录后默认进入本页。屏幕右缘常驻**悬浮急停球**，全程可一键急停。

### 3.2 界面元素

| 区域 | 元素与说明 |
| --- | --- |
| 顶部导航栏 | 页签：管理员（仅管理员角色）、操作、主控、数据分析（仅管理员角色）、设置；右上为当前用户与退出登录入口 |
| 视频区 | 「RDK 视频源」实时画面，**仅支持 RDK X5 真实视频流**；可切换「前视相机」（camera_1）/「吸口相机」（camera_2）；显示分辨率、帧率与「≈链路时延 XXXms」（由帧发送时刻 `sent_ts` 端到端实测，时钟异常时显示为空，不造数） |
| AI 识别 | 画面叠加 YOLO11 分割检测框（标签 + 置信度百分比，如"海参 · 置信度 92.3%"）；侧栏「实时检测日志」滚动输出识别结果，无目标时显示"暂无检测结果" |
| 遥测卡片 | 当前深度（m）、机器温度（°C）、剩余电量（%）、电池电压（V）、超声距离（m，含"前方 X.XX m"）等，均来自传感器真实回传 |
| 推进器控制 | 方向按钮：前进(W)、后退(S)、左转(A)、右转(D)、上浮、下潜，支持键盘（W/A/S/D、Shift+空格）；推进器动力百分比显示；解锁/已锁定状态（已解锁/已锁定）与 STOP 按钮 |
| 快捷操作 | 一键上浮、坐标归零、开启补光/关闭补光、快照捕获（抓取采集） |
| 照明系统 / 报警提醒 | 补光灯开关与异常报警显示 |
| 底部状态栏 | 连接状态圆点：绿=已连接、黄=重连中、红=离线；右侧显示连接消息与版本号 (v3.0.0) |

### 3.3 操作步骤（视频监控与 AI 检测）

1. 登录后进入主控页，确认视频区出现 RDK 实时画面且「≈链路时延」有数值；
2. 点击「前视相机」/「吸口相机」切换 camera_1 / camera_2 视角；
3. 观察 AI 识别区：检测框实时叠加，侧栏滚动显示「标签 · 置信度」日志；
4. 作业中关注遥测卡片数值与报警提醒区。

### 3.4 操作步骤（推进器控制）

1. 确认底部状态栏为绿色"已连接"；
2. 按住方向按钮（或键盘 W/A/S/D）推进，**松开即停**；
3. 需要垂直机动时使用「上浮」「下潜」；
4. 点击「坐标归零」清除姿态基准；需紧急上浮时点击「一键上浮」。

### 3.5 操作步骤（灯光与快照）

1. 点击「开启补光」/「关闭补光」控制照明系统；
2. 需要留证时点击「快照捕获」，抓拍图保存到 RDK X5 快照目录（可在数据分析页"作业快照画廊"回看）。

### 3.6 悬浮急停球（EmergencyOrb）

**功能说明**：红色悬浮球停靠屏幕右缘垂直居中，不遮挡页内既有急停按钮，登录页不显示。它是最快触达的急停入口——**免确认对话框**，长按充能即触发。

**操作步骤**：

1. 长按急停球，环形充能动画开始充满；
2. **充满瞬间立即触发急停**（触发时有短促"重触感"反馈）；未充满即松手则取消，不会误触发；
3. 触发后命令经真实链路下发（停止全部推进器），并等待后端 ack 确认：
   - 确认成功：正常提示；
   - ack 失败（如权限不足 forbidden/未授权 unauthorized）：升级为**红色常驻告警**，直到下一次急停获后端确认或操作者手动关闭；
   - 未连接/通道不可用：如实提示发送失败，**绝不无条件报成功**。

### 3.7 数据断链提示（信号丢失徽标）

任一通道数据中断超过 5 秒，对应区域显示「⚠ 信号丢失」徽标并**冻结最后真实值**；数据恢复后徽标自动消失。系统不使用兜底假值，因此断链期间请以徽标为准判断数据时效。

## 4. 操作页（控制操作）

### 4.1 功能说明

操作页面向驾驶操作，提供方向推进、紧急停止、吸捕与灯光控制，以及实时运行状态读数。方向按钮为**按住推进、松开即停**的操纵方式。

### 4.2 界面元素

| 区域 | 元素与说明 |
| --- | --- |
| 实时运行状态 | 探测深度（实时读取）、机器温度、电池电压、通信延迟等真实遥测 |
| 方向控制 | 前进/后退/左转/右转/上浮/下潜按钮，按住推进、松开即停；显示当前推进器动力百分比 |
| 紧急制动系统 | 「紧急停止 (STOP)」按钮 |
| 吸捕控制 / 灯光与吸捕 | 「抓取（吸力 100%）」「释放（吸力 0%）」、灯光开/关 |
| 辅助系统 / 操作说明 | 辅助状态与"方向按钮按住推进、松开即停"等操作提示 |

### 4.3 操作步骤

1. 点击顶部页签「操作」进入操作页；
2. **方向推进**：按住方向按钮推进，松开即停；拖动推进器动力滑条调整动力百分比；
3. **紧急停止**：点击「紧急停止 (STOP)」，弹出确认对话框"确定要执行紧急停止吗？将立即停止全部推进器。"，点击「确认停止」执行（出现"已停止全部推进器"提示），点击「取消」放弃；
4. **吸捕作业**：点击「抓取（吸力 100%）」启动吸捕（提示"已发送吸捕抓取命令，吸力 100%"）；点击「释放（吸力 0%）」停止吸捕；
5. **灯光**：点击灯光开关切换补光，提示"已发送灯光开启/关闭命令"。

## 5. 数据分析

### 5.1 功能说明

数据分析页提供**统计分析看板**与**作业快照画廊**。全部曲线、KPI 与统计摘要均来自后端 SQLite 中 `source='rdk'` 的真实记录；仿真（sim）数据不计入真实统计——所选传感器在当前时间范围内无真实数据时明确提示"尚无真实数据，仿真数据不计入"。页面标注"数据来源：后端真实链路聚合数据""全部结论来自真实聚合数据"。

### 5.2 界面元素

| 区域 | 元素与说明 |
| --- | --- |
| 时间范围 | 快捷档：1小时 / 6小时 / 24小时 / 7天；自定义起止日期；点击「应用范围」生效；聚合窗口（bucket）按范围自动解析 |
| 传感器序列 | 深度、压力、深度计温度、水温1、水温2、光照（前视）、光照（下视）、超声（吸口前方/下视高度）等多序列勾选，单位随序列显示 |
| 趋势曲线 | 多序列聚合曲线图；每序列显示条数与「原始点数」 |
| 统计摘要 | 每序列 最大 / 最小 / 平均 / 最新 值与趋势（↑/↓ 百分比） |
| 导出 | 「导出 CSV」生成 `sensor_series_时间戳.csv`（UTF-8 BOM，Excel 可直接打开），提示"导出成功"与保存路径，可「复制路径」 |
| 作业快照画廊 | 「刷新快照」拉取 RDK X5 快照目录缩略图（`list_snapshots`/`fetch_snapshot`，仅允许快照目录内文件，拒绝路径穿越）；支持复制路径；无快照时显示"暂无快照" |
| 数据链路 | 断链时显示「数据链路中断」徽标（同主控页 5 秒规则） |

### 5.3 操作步骤

1. 点击顶部页签「数据分析」（管理员角色可见）；
2. 选择时间范围（如 24 小时）或自定义起止日期，点击「应用范围」；
3. 勾选需要查看的传感器序列（如 深度、水温1），查看聚合曲线与 最大/最小/平均/最新 统计及趋势；
4. 点击「导出 CSV」保存报表，按提示路径取文件；
5. 切换到「作业快照画廊」点击「刷新快照」回看作业抓拍，可对单张快照「复制路径」。

## 6. 管理与诊断（管理员）

### 6.1 功能说明

管理员页面向 super_admin/admin 角色（普通用户导航项置灰加锁），提供 KPI 监控、用户与角色管理、操作日志审计、RDK X5 地址配置、摄像头信息与链路诊断。

### 6.2 界面元素

| 区域 | 元素与说明 |
| --- | --- |
| KPI 卡片 | 用户总数、活跃会话、24h 控制日志、24h 传感器数据、数据库大小（MB）、后端运行时长（X天X时）；标注"数据来源：本地后端数据库 · 仅统计 rdk 真实链路 · 30 秒自动刷新" |
| 用户与角色 | 用户列表"从后端数据库读取，支持增删改与重置密码"；新建/编辑用户（用户名、密码、姓名、角色：管理员/普通用户、「允许登录」开关）；「重置密码」；「删除用户」带确认；「刷新用户列表」 |
| 操作日志 | 搜索框（按操作人或动作过滤）、列（操作时间/操作人/动作模块/动作内容/成功）、分页（上一页/下一页、当前页/总页）、"共计 N 条操作记录"、「导出」（`system_logs_时间戳.csv`） |
| RDK X5 地址配置 | RDK X5 IP 与端口输入、「保存并连接」；提示"修改需管理员权限，保存后自动重连网关"；成功提示"RDK 地址已更新为 host:port，后端正在重连网关"；显示摄像头列表、摄像头能力与活动摄像头 |
| 链路诊断 | 「链路诊断」按钮实时采集链路状态，展示后端健康检查（/api/health）与统计（/api/stats）真实数据 |

### 6.3 操作步骤（用户管理）

1. 以管理员身份登录，点击页签「管理员」；
2. 在「用户与角色」点击新建用户，填写用户名、密码（必填且两次一致）、姓名，选择角色与「允许登录」，保存；
3. 需要时对既有用户「重置密码」（成功提示「XX」的密码已重置）或「删除用户」（需确认）；
4. 停用某账号时关闭其「允许登录」开关：停用后该账号登录将被拒绝。

### 6.4 操作步骤（日志审计）

1. 在「操作日志」搜索框输入操作人或动作关键词过滤；
2. 用「上一页」「下一页」翻页浏览，共 N 条记录实时显示；
3. 点击「导出」保存日志 CSV，按提示路径取文件。

### 6.5 操作步骤（链路配置与诊断）

1. 在「RDK X5 地址配置」输入板卡 IP 与端口，点击「保存并连接」，等待"后端正在重连网关"提示；下方查看摄像头列表与活动摄像头；
2. 点击「链路诊断」采集当前链路状态，检查后端健康与统计读数；
3. 若提示"后端拒绝：需要管理员角色"，说明当前账号权限不足，请切换管理员账号。

## 7. 设置

### 7.1 功能说明

设置页集中管理显示、语言、账户安全、RDK 连接、启动项、无障碍与维护。显示类设置修改后**即时生效并自动保存**。

### 7.2 界面元素与操作步骤

| 分区 | 设置项与操作 |
| --- | --- |
| 显示设置 | 主题模式：明亮模式 / 深色模式 / 自动切换主题；界面缩放（百分比，如 100%）；全局字体大小（pt）；提供正文示例预览；「恢复默认值」一键还原（提示"已恢复默认显示设置"） |
| 语言与地区 | 界面语言：中文（简体）；时区、日期与时间格式跟随操作系统区域设置 |
| 账户与安全 | 显示"登录用户名：X · 用户ID：Y"；「修改密码」：输入新密码与确认新密码（"两次输入的密码不一致或为空"时拒绝提交），成功提示"密码修改成功"，失败如实提示原因 |
| RDK X5 连接 | 显示当前连接状态（"已连接 RDK X5"或"未连接，请确认网线直连、板卡 IP 与本机网段一致"）；可修改 IP/端口并「保存并连接」；提示"修改需管理员权限，保存后自动重连网关" |
| 启动选项 | 开机自动启动（安装版注册系统启动项后生效） |
| 无障碍 | 「减少动画效果」：减少界面过渡动画，提升性能、减少眼睛疲劳；开启后页签转场等动画时长归零 |
| 维护 | 「清除缓存」（提示"缓存已清除"）；危险区域操作谨慎使用 |
| 会话 | 「退出登录」：确认对话框"确定要退出当前账户吗？退出后需重新登录。"，确认后返回登录页 |

### 7.3 操作步骤（普通用户自助改密）

1. 以普通用户登录，进入「设置」→「账户与安全」；
2. 输入新密码与确认新密码，点击「确认修改」；
3. 看到"密码修改成功"提示后，新密码即时生效。

## 8. 状态指示与常见问题

### 8.1 全局状态指示

| 指示 | 含义与处置 |
| --- | --- |
| 底部状态栏圆点（绿/黄/红） | 已连接 / 重连中 / 离线；右侧文字为服务层实时连接消息 |
| 「⚠ 信号丢失」徽标 | 对应通道数据中断超过 5 秒，数值冻结为最后真实值；恢复后自动消失；期间不要将冻结值当作实时值 |
| 「⚠ 仿真数据——非真实硬件回传」黄色横幅 | 后端处于 sim 模式时全局显示；该模式下数据仍走完整链路用于联调演示，**不得当作真实作业数据** |
| 「≈链路时延 XXXms」 | 视频端到端时延实测值；时钟异常时显示为空（不造数） |
| 红色常驻急停告警 | 急停命令未获后端确认；请检查连接与账号权限，恢复后重新触发急停或手动关闭 |

### 8.2 常见问题

| 现象 | 处置 |
| --- | --- |
| 登录提示错误无法进入 | 核对用户名/密码；账号被停用（「允许登录」关闭）也会被拒绝；忘记密码联系管理员在「管理员 → 用户与角色」重置 |
| 超管登录后强制弹改密框 | 属正常安全机制（仍在使用初始口令），修改后方可进入主界面 |
| 视频区无画面 | 确认底部状态栏已连接、RDK X5 网关已运行；系统仅接受 RDK X5 真实视频流 |
| 管理员/数据分析页签置灰带锁 | 当前账号为普通用户，需管理员角色 |
| 保存 RDK 地址提示"需要管理员角色" | 改用管理员账号操作 |
| 数据分析提示"尚无真实数据，仿真数据不计入" | 所选时间范围内无 `source='rdk'` 真实记录；请先进行真实作业采集，或确认当前处于真实链路模式 |
